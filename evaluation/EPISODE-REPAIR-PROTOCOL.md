# Episode-preserving companion repair and BMTR-STRESS-2

Specified 2 November 2026 before executing the new script. These are post-audit experiments motivated by the lifecycle/episode ablation. Preserve original generator, vendor source, BMTR-1 inputs and earlier outputs. No model calls, people, private browsing histories or external service calls.

## Companion policy

Store each observation as a separate immutable episode. Never merge equal values across intervals and never use a global present lifecycle status to suppress historical records. At query time, use only observations inserted by knowledge time whose asserted interval contains requested valid time. Restrict to the requested subject/predicate. Select the cohort with greatest asserted effective start. Within that cohort count distinct supporting provenance URLs or explicitly declared source-origin groups for each value. Select a unique highest-support value if it meets the support threshold, otherwise abstain. Do not fall back to older cohorts. Return an observed representative with that value. Support counts are not calibrated truth probabilities. Declared origins are assumed available metadata, not inferred source independence or authenticated provenance.

Compare actual unchanged NuggetStore Active, unmerged latest-valid ordered by effective start/observation time/ID, and three companion conditions: episode plurality with minimum one origin; corroboration with minimum two URLs; corroboration with minimum two declared origins. All receive identical observable fields. The core's standard provenance storage does not interpret origin-group metadata; this difference is explicit. Common scorer labels and truth are never passed to any method. Copy or strip records at the ingestion boundary to enforce this separation.

## Versioned stress extension

BMTR-STRESS-2 uses 20 new world seeds 28101–28120. Each has 40 fictitious entities, one of three functional predicates, six episodes with nonrepeating adjacent but potentially recurring values, irregular 2–6 day durations, observation delay up to 0.75 days, and an eight-day supplied expiry policy. Query current/historical state at days 10, 20 and 32; add 24 unseen-entity queries. Preserve separate world truth and observable observations. No natural-language extraction is claimed.

Cross three binary factors for 160 configurations: (a) effective-start error zero or uniform ±1 day, (b) report-missing probability zero or 0.25, and (c) zero or 0.25 of episodes receiving a correlated false-claim cluster. Use independent seeded streams for true transitions, temporal errors, missingness, copied-claim activation and observation delays. The same underlying world and random draws are reused across factor cells. These are controlled stress levels, not estimates of errors in real deployments.

Each episode has two independent correct source reports. Activated false clusters add three distinct mirror URLs carrying the same incorrect value and explicitly naming one common source origin. Provenance grouping is visible to every method and never identifies which value is correct. The URL-vs-origin support ablation tests whether counting mirrors as independent evidence changes admission. Origin metadata are an assumption of this diagnostic; missing or dishonest origin labels remain untested. Apply missingness independently to every potential report, including copies. Start perturbation is shared across reports describing an episode, with interval end equal to observed time plus eight days; do not use hidden episode identity in policy grouping. Independent delay and report ordering can make latest observation choose a copy. Save every observable input and query, with truth in a separate scorer-only field.

Run all five methods with identical insertion order and metadata, report paired changes and 20-world Student-t intervals (t19=2.093024). For uncertainty effects compare paired within-world factor cells rather than treating 160 configurations as independent worlds. Report current and historical accuracy, wrong-answer rate, coverage, correct abstention and evidence recall. Save all method outputs, counts and label-blind coverage matches. Do not tune thresholds on outcomes or describe source-origin grouping as a general semantic validator.
